02 · Put it online

Free hosting, with the tradeoffs made clear.

A static host publishes HTML, CSS, JavaScript, images, and other files. Free plans are excellent for personal pages, but storage, file types, custom domains, and upload tools vary.

Easy first host

Neocities

Free

A friendly static host with a browser editor, a free subdomain, no ads, 1 GB of storage, and 200 GB of bandwidth.

Know the limits

The free tier restricts some file types, including audio. Custom domains, unrestricted file uploads, hotlinking, and CORS support are Supporter features.

Visit Neocities →
Flexible files

Nekoweb

Free

Static hosting built for personal websites, with zip imports and no restriction on file types. It is a useful option when one host needs to hold both your page and your media.

Know the limits

Custom domains and advanced upload methods such as FTP, WebDAV, and Git belong to paid supporter tiers. Review the current plans before moving a large site.

Visit Nekoweb →
Version controlled

GitHub Pages

Free

Publish a static site from a public repository, keep a history of every change, and use either a github.io address or your own domain.

Know the limits

It requires a GitHub and Git workflow. Published sites have a 1 GB limit and a soft bandwidth limit of 100 GB per month. GitHub Pages is not intended for e-commerce or sensitive transactions.

Explore GitHub Pages →

For musicians

Your page host and audio host can be different.

For a track to play inside IndieNodes, its link must point directly to an audio file on a host that allows cross-origin requests. A platform player from Bandcamp, YouTube, Spotify, Apple Music, or SoundCloud cannot provide that file to the ring.

Internet Archive is the standing recommendation for free, durable audio hosting. File Garden also provides free direct file links. File Garden hosts the media, not the web page, so pair it with a page host such as Neocities.

03 · Publish something small

Your first version only needs a few things.

  1. 1

    Say who you are

    A short introduction and one clear way to contact or follow you is enough.

  2. 2

    Share a few things you make

    Pick work that represents you. You can add archives and galleries later.

  3. 3

    Check it on a phone

    Make sure text is readable, links are easy to tap, and images fit the screen.

  4. 4

    Describe your images

    Useful alt text helps more people understand and enjoy what you publish.

  5. 5

    Let the web connect you

    Add links to sites you enjoy, join a webring, and update at your own pace.
